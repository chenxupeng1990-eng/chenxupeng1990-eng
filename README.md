# 坐标 · ZUOBIAO

**AI × 品牌增长 × 内容系统**

> 把业务判断写成方法，把方法做成可复用的 AI 工作流。

我做品牌策略，也构建让策略进入真实业务的内容与 AI 工作流。从问题和判断依据出发，整理资料、组织表达、比较实际产出，再把人工确认与交付检查放进流程。留下来的方法，应该能在下一次任务中被调用和检验。

## 关注的连接 · FOCUS

- **判断 / Judgment**：明确受众、场景与关键选择，让策略有依据。
- **表达 / Expression**：用内容结构与真实样张检验观点是否清楚。
- **流程 / Workflow**：定义输入、评审、复核与交付，让协作可复用。

## 公开项目 · SELECTED WORK

### 01 · [QIFEI Proposal Skill](https://github.com/chenxupeng1990-eng/qifei-proposal-skill)
